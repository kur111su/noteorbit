## 保留的限制

1. SQL.js 使用内存数据库和快照导出，文件补偿没有覆盖所有断电时刻。大库与高可靠场景需要带日志的持久层。
2. 列表渲染全部匹配资料，星系无分层加载；需虚拟列表、分页和图谱裁剪后再承诺大规模性能。
3. 文件完整字节/文本传入渲染器，大 PDF、图片有内存开销，后续可评估受控文件协议或分块读取。
4. 外部移动、多个编辑器修改或多个程序写同一库暂无冲突解决；没有监听、重新定位和历史。
5. 浏览器示例的文件与元数据分属两类存储，没有桌面级事务保证或正式迁移接口。
6. 备份未加密、未签名；近上限大包和断电恢复尚未做压力测试。

这些限制已同步写入 README。
